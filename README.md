# VerletIntegrationSolver
2D Verlet integration physics solver in C++ with SFML

Inspired by Pezzza's Work on YouTube

## Build & run
Requires: g++, cmake, make, SFML 2.6 (dev package)

    git clone https://github.com/TheV1be/VerletIntegrationSolver.git
    cd VerletIntegrationSolver
    make

## Controls
- R: reset
- Space: stream
- M/N: add/remove streams
- Left click: spawn
- Right click: attract/repulse
- I: change attraction/repulsion of Right click
- WASD: change gravity
- C: toggle color by speed
- B: toggle circular bounds
- 1: spawn rope at mouse
- 2: spawn bridge at mouse
- 3: spawn cloth at mouse
